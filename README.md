# ⏱️ Cronômetro Simples

Um cronômetro digital moderno, responsivo e com precisão de centésimos de segundo, desenvolvido para praticar conceitos essenciais de desenvolvimento web (HTML, CSS e JavaScript) e alinhamento avançado com Flexbox.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

*   **HTML5:** Estruturação dos elementos, display de tempo e botões de controle.
*   **CSS3:** Estilização moderna, centralização com Flexbox e responsividade para dispositivos móveis (`@media queries`).
*   **JavaScript (ES6):** Lógica matemática do tempo, controle de loops com `setInterval` e manipulação do DOM.

## ✨ Recursos e Diferenciais

*   **Precisão de Centésimos de Segundo:** Ideal para medições rápidas.
*   **Interface Estável (Anti-Tremor):** Uso da propriedade `tabular-nums` combinada com larguras fixas via CSS, garantindo que os números não fiquem "dançando" na tela enquanto correm.
*   **Design 100% Responsivo:** O layout se adapta perfeitamente a computadores, tablets e smartphones.
*   **Controles Intuitivos:** Botões táteis com efeitos visuais ao passar o mouse (`:hover`) e ao clicar (`:active`).
