# ⏱️ Cronômetro Online

Um cronômetro digital moderno, responsivo e minimalista desenvolvido em JavaScript puro. O projeto conta com um layout elegante em formato de "card" para computadores e uma interface minimalista e fluida adaptada para telas de celulares.

---

## 📱 Recursos e Diferenciais

* **Responsividade Avançada:** Design adaptável que muda de comportamento para garantir a melhor experiência no PC e no Mobile.
* **Efeito Ativo nos Botões:** Transições e microinterações táteis ao clicar ou tocar nos botões.
* **Alinhamento Tabular:** Números com espaçamento fixo para evitar que o layout "fique tremendo" enquanto o tempo corre.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias web fundamentais, sem a necessidade de frameworks externos:

* **HTML5:** Estruturação semântica dos elementos.
* **CSS3:** Estilização moderna utilizando Flexbox, Media Queries para responsividade e variáveis de transição.
* **JavaScript (ES6):** Lógica do cronômetro utilizando manipulação do DOM e a API `setInterval`.
